# A Game Studio game

This project is one game made in **Game Studio**. Build it and play it in
Game Studio: describe changes in the game's chat there and play them straight away.

| File | What it is |
| --- | --- |
| `game.html` | The whole game: one self-contained web page. |
| `game.json` | Its name, description, controls, genre and art kit. |
| `art.json` | Art, sounds and voices made for this game only. |

Characters and assets from Game Studio's Characters and Assets tabs are shared
by every game, so they live in Game Studio, not here. Your saved progress stays
in Game Studio too.

Every change is kept in this project's history, so you can see what changed and
go back. Edits made here reach Game Studio within a minute (or at once when the
game's assistant makes them), and changes made in Game Studio come back here.

## Building it together

Invite friends with **Share → Work together** in this project. Editors can
change the game here; viewers can watch and play.

- **Play:** press **Build** on the *Play* creation to try the game right here,
  with all its art. It plays the files as they are now, including your edits.
  (Saves start fresh and the Möbius voice is off in this preview.)
- **Who's on what:** opening a file shows everyone else that you're working on
  it, and the activity list shows every change and who made it. If the game is
  split into files under `src/` (levels, player, enemies, art, sound...), take
  one part each so you never edit the same file at once.
- **Asking the AI:** the game's AI assistant lives in the owner's Game Studio.
  Write your wishes in `requests.md` here and the owner can hand them to it.
